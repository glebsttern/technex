# Проект: Технекс — мобильная версия (new-site)

**Перед любой работой прочитай `_project/RULES.md`. Это не рекомендации, а правила.**

Коротко, самое жёсткое:

1. **Папку `C:\Work\technex\old` не читать никогда.** Ни файлом, ни поиском, ни «только
   посмотреть». Только по явному запросу пользователя в текущем сообщении.
2. **Папку `C:\Work\technex\snapshot` не менять.** Это эталонный слепок живого сайта.
3. **Ничего не улучшать.** Старые технологии (инлайн-стили, `width=`, таблицы в вёрстке,
   `&nbsp;`, классы Drupal) сохраняются как есть. Рефакторинг запрещён.
4. **Десктоп не ломать.** Мобильные правки — только внутри `@media (max-width: …)`, дописыванием,
   не переписыванием существующих правил.
5. **Все наши стили — в `themes/technex/css/mobile.css`**, а не в `style.css` (п. 5.1 правил).
   Файл подключается только после `style.css`. Единственное исключение — `font-display`
   у `@font-face "Onder"`, оно правится на месте и помечено комментарием.
6. **Каждая правка — запись в `_project/CHANGELOG.md`** с типом MOBILE / CONTENT / MARKUP / BUG.
7. **Компоненты — по реестру `_project/COMPONENTS.md`.** Шапка, меню, поиск, подвал одинаковы
   на всех 304 страницах; правка компонента вносится во все страницы сразу, скриптом.
8. **Проверка только в браузере**, через `node _project/serve.js 8080`, в 375×812 и на десктопе.

Что где:

- `_project/RULES.md` — правила целиком
- `_project/COMPONENTS.md` — типы страниц и реестр компонентов
- `_project/CRAWL-REPORT.md` — отчёт по слепку: что спарсено, что битое на живом сайте
- `_project/CHANGELOG.md` — журнал правок (он же ТЗ программисту)
- `_project/BACKLOG.md` — согласованная очередь правок (сделанное уходит в журнал)
- `_project/crawl-manifest.json` — машинная расшифровка обхода
- `_project/serve.js` — локальный сервер, понимает живые URL сайта
- всё остальное в `new-site` — зеркало сайта по живым путям
