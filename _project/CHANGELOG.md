## 2026-10-20 — мобильное меню: панель «выезжала и уезжала» при каждом переходе
- Тип: MOBILE
- Где: `themes/technex/css/style.css`, тот же блок `@media (max-width: 820px)` в конце файла
  (компонент «меню», все 304 страницы)
- Было: до того как JS поставит `.is-burger`, `.nav` — обычное горизонтальное меню без
  `transform`. Вместе с классом приезжают сразу и `transform: translateX(100%)`, и
  `transition: transform 0.3s`, поэтому браузер проигрывает анимацию закрытия панели.
  Страница к этому моменту уже показана (`body.is-ready` снимает `opacity: 0`), и на
  каждом переходе по внутренней ссылке в узком окне видно, как панель меню выезжает
  справа и уезжает обратно. Поймано скринкастом: панель видна в кадрах с ~900 мс после
  клика.
- Стало: закрытое состояние задано заранее — `.mainmenu .nav { transform: translateX(100%);
  visibility: hidden }` и `.mainmenu .nav.is-open { transform: translateX(0); visibility:
  visible }` внутри того же медиазапроса. При добавлении `.is-burger` значение `transform`
  не меняется, анимировать нечего. Открытие и закрытие по кнопке анимируются как раньше.
- Зачем: дёрганье на каждом переходе, самый заметный дефект мобильной версии после
  неработающего меню.

## 2026-10-20 — шрифты: убран прыжок вёрстки после подгрузки шрифта
- Тип: MARKUP (правка темы и `<head>` всех страниц)
- Где: `themes/technex/css/style.css` — `@font-face` для Onder; ссылка на Google Fonts
  в `<head>` всех 304 HTML (правка скриптом, строка была одинаковой везде)
- Было: `font-display: swap` у Onder и `&display=swap` в ссылке на Manrope. Занавес
  `body.is-ready` снимается по готовности DOM, то есть до загрузки шрифтов, поэтому

- Стало: Onder — `font-display: block` (файл лежит на своём же сервере, приезжает быстро,

  около 100 мс, не успел — страница остаётся на запасном и **позже не перевёрстывается**;
  на следующих страницах шрифт берётся из кэша. Так внешний сервис не может ни подвесить
  текст, ни сдвинуть вёрстку.
- Зачем: убрать прыжок контента при каждом переходе.
- Проверено: переход между страницами в окне 500×860 — сдвиг контента 0 px (замеры
  положения заголовка и первого абзаца на 0 / 150 / 400 / 900 / 2000 мс). Первый заход с

  Замечание на будущее: Manrope тянется с внешнего домена; на проде его стоит положить
