# Технекс — мобильная версия. Что подключить

Пакет от 03.11.2026. Внутри два файла темы и список того, что осталось вне них.

## 1. Два файла

- `css/mobile.css` → `themes/technex/css/mobile.css`
- `js/app.js` → `themes/technex/js/app.js` (заменяет существующий)

## 2. Подключение, порядок обязателен

`mobile.css` подключается ТОЛЬКО ПОСЛЕ `style.css`. В Drupal — строкой следом
за `style.css` в `technex.libraries.yml`:

```yaml
global-styling:
  css:
    theme:
      css/style.css: {}
      css/mobile.css: {}      # <- эта строка, именно после style.css
```

Часть правил переопределяет тему (`.mainmenu__actions` переводится на флекс,
заголовок баннера снимается с Onder, меняется сетка блоков направлений).
Если подключить раньше `style.css` — поедут шапка и баннеры.

Отключается тоже одной строкой: убрать `css/mobile.css` — и сайт вернётся
к прежнему виду, кроме четырёх пунктов ниже.

## 3. Что осталось вне mobile.css

Это правки, которые из отдельного файла не делаются:

1. `font-display: block` у `@font-face "Onder"` в `style.css` — дескриптор
   `@font-face` надёжно не переопределяется извне. В коде помечен комментарием.
2. `display=optional` в ссылке на Google Fonts в `<head>`.
3. Разметка шапки с мессенджерами (telegram / whatsapp / viber) — на всех
   страницах, и кнопка «Подробнее» на главной.
4. `Drupal.behaviors.technexCatMore` в `app.js` — раскрытие списков направлений.
