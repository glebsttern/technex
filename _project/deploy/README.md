# Технекс — мобильная версия. Что это за архив

Это **рабочая копия сайта**, снятая со стенда `web.mydns.su`, плюс наши правки
мобильной вёрстки. Архив справочный: посмотреть результат и свериться.

## ⚠️ Главное: HTML отсюда в Drupal не копировать

Файлы `.html` в архиве — это **вывод** Drupal, сохранённый обходчиком, а не
шаблоны темы. Если положить их в проект, сайт сломается.

В Drupal переносятся только два файла:

- `themes/technex/css/mobile.css`
- `themes/technex/js/app.js`

Как подключить — ниже, пункт 2.

## 1. Посмотреть результат

Нужен Node.js. Из папки архива:

```
node _project/serve.js 8080
```

Откроется на `http://localhost:8080/`. Сервер понимает живые адреса сайта:
`/uslugi`, `/izgotovlenie/krany-mostovye.html`, пагинацию `?page=1`.
Смотреть в 375 и на десктопе — правки видны в обоих режимах.

## 2. Подключить правки

`mobile.css` подключается ТОЛЬКО ПОСЛЕ `style.css` — строкой следом
в `technex.libraries.yml`:

```yaml
global-styling:
  css:
    theme:
      css/style.css: {}
      css/mobile.css: {}      # <- эта строка, именно после style.css
```

Часть правил переопределяет тему (`.mainmenu__actions` переводится на флекс,
заголовок баннера снимается с Onder, меняется сетка блоков направлений).
Подключить раньше `style.css` — поедут шапка и баннеры.
Отключается тоже одной строкой.

## 3. Что осталось вне mobile.css

Эти правки из отдельного файла не делаются, их надо перенести руками:

1. `font-display: block` у `@font-face "Onder"` в `style.css` — дескриптор
   `@font-face` надёжно не переопределяется извне. В коде помечен комментарием.
2. `display=optional` в ссылке на Google Fonts в `<head>`.
3. Разметка шапки с мессенджерами (telegram / whatsapp / viber) — на всех
   страницах, и кнопка «Подробнее» на главной. В архиве видно, как должно
   получиться; в проект это переносится в Twig-шаблоны.
4. `Drupal.behaviors.technexCatMore` в `app.js` — раскрытие списков направлений.

## 4. Где что лежит

- `_project/CHANGELOG.md` — журнал всех правок: было / стало / зачем / на каких
  ширинах проверено. По сути — ТЗ и обоснование каждой строки в `mobile.css`.
- `_project/COMPONENTS.md` — сквозные компоненты (шапка, меню, поиск, подвал)
  и типы страниц.
- `_project/BACKLOG.md` — что ещё в очереди и что снято решением заказчика.
- `_project/CRAWL-REPORT.md` — как снимался слепок, что на живом сайте битое.
- `_project/serve.js` — локальный сервер из пункта 1.
- всё остальное — зеркало сайта по живым путям.

## 5. Известное, но не наше

В разметке всех страниц лежит инлайн-счётчик Яндекс.Метрики с двумя ошибками:
лишняя закрывающая скобка в конце IIFE и обращение к необъявленной переменной
`inf`. Браузер выдаёт `SyntaxError`, счётчик не выполняется — **метрика не
работает**. Это пришло с живого сайта, к нашим правкам отношения не имеет.
На остальной JS не влияет: счётчик лежит отдельным блоком.
